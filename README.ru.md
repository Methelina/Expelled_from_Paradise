# Expelled from Paradise (exl)

2D-игра, сделанная на **Unity 5.1.3f1** (старый проект с бинарной сериализацией ассетов).

[README in English](README.md)

## О проекте

`exl` — прототип 2D action/adventure игры: тайловые уровни, собственные спрайты
персонажей, ИИ врагов, заклинания/эффекты и звук. В репозитории лежит весь
проект Unity, включая сторонние плагины.

## Структура проекта

```
Assets/
├── arts/          # Арты
├── source/        # Код и контент игры, разбит по темам:
│   ├── AI/        # ИИ врагов
│   ├── Anim/      # Анимации
│   ├── Common/    # Общий код и префабы
│   ├── Control/   # Управление игроком / ввод
│   ├── Editor/    # Скрипты редактора
│   ├── FX/        # Визуальные эффекты
│   ├── Prop/      # Пропы / объекты
│   ├── Sound/     # Звук
│   └── UI/        # Интерфейс
├── scenes/        # Сцены Unity (testbed, CellCopy, CellCopy2)
├── prefab/        # Префабы
├── Resources/
├── sound/         # Аудио
├── TileBrushes/   # Кисти тайлов для построения уровней
└── TextMesh Pro/
```

### Сторонние плагины (внутри Assets/)

| Плагин | Назначение |
|---|---|
| AstarPathfindingProject | Поиск пути A* для ИИ |
| PlayMaker | Визуальное программирование (FSM) |
| iTween | Библиотека анимации/твининга |
| Rotorz | Тайловая система |
| Haste | Быстрый поиск ассетов |
| QHierarchy | Улучшения иерархии |
| StompyRobot | Инструменты (SRDebugger) |

## Требования

- Unity **5.1.3f1** (проект использует бинарную сериализацию той эпохи и
  не гарантированно откроется в новых версиях Unity без миграции)

## Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Methelina/Expelled_from_Paradise.git
   ```
2. Откройте папку проекта в Unity 5.1.3f1.
3. Откройте сцену из `Assets/scenes/` и нажмите Play.

## Примечания

- Проект изначально версионировался в Mercurial (`.hg`); этот репозиторий —
  его git-зеркало. `Library/`, `Temp/` и прочие генерируемые папки игнорируются —
  см. [.gitignore](.gitignore).
- Файлы `*.meta` отслеживаются и обязательны: Unity сопоставляет ассеты с их
  настройками импорта по GUID, поэтому их нельзя удалять или править вручную.
